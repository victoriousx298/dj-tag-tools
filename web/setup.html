Welcome to DJ Tag Tools

Tidy up new tracks before they go into Rekordbox: convert WAV to MP3, fix artist / title tags and file names, fill in missing years, genres and BPM. Everything runs on your computer, and you always see a preview before any file is touched.

How it works

  1. Import (home page): pick a folder with new WAV / MP3 files, check the preview table (edit any cell you like), press Apply. Changed MP3s are backed up first.
  2. BPM & Fixes: pick a Rekordbox playlist (or upload an iTunes / Rekordbox playlist TXT), tick what you want (BPM, year, genres, tag cleanup), preview, then Write changes.
  3. Backups live in the backups/ folder next to the tool and are deleted automatically after 30 days.
  4. You can come back to this page any time via the Setup link at the top.

Your library

Where your new tracks land (e.g. Downloads or your Music library). The Import page opens here first; you can still choose another folder there.
